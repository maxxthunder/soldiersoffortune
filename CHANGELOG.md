# Changelog

Changes to the [password generator](https://maxxthunder.github.io/soldiersoffortune/). The version is shown at the bottom of the page.

## 1.1.0 (2026-10-27)
- A password decodes as soon as all 12 characters are typed or pasted; no need to press Decode.
- Loading a password can be undone, like Max everything and Fresh party.
- Keyboard shortcuts on a computer: paste a password anywhere on the page to decode it, C copies, B opens Big text, Z undoes.
- On iPhone, sliders follow your finger anywhere along them instead of scrolling the page.
- On phones, a slider no longer jumps under your finger when the line above it changes after loading a password.
- Big text on a phone held sideways opens at its top and scrolls, so nothing is cut off.
- The decode box turns off autocorrect and types in capitals on phones.

## 1.0.10 (2026-10-16)
- The page has a tab icon.
- Super Nintendo replaces SNES in Big text, decode messages and the page text.
- Big text fills 80% of the screen's width, and the tap-to-cross-off groups are gone.
- On small phones, the notes no longer scroll sideways, and the line above the Big text password wraps evenly.

## 1.0.9 (2026-10-15)
- A mistyped password from another console now gets suggested fixes too, not only one from the selected console.

## 1.0.8 (2026-10-15)
- The password uses Space Mono, a bolder font that's easier to read from across the room.

## 1.0.7 (2026-10-15)
- The console buttons read Super Nintendo, Genesis/Mega Drive and Amiga, and stay on one line on phones.
- Small code cleanups.

## 1.0.6 (2026-10-15)
- The page has explicit `<head>` and `<body>` tags, so Google Search Console can find its verification tag.
- Fixed the HTML validation errors: the logo has a placeholder image until it loads, and the lives, level and money labels no longer wrap their buttons.

## 1.0.5 (2026-10-15)
- Verified the site with Google Search Console.

## 1.0.4 (2026-10-15)
- Big text reminds you to start the game with the right number of players.
- Max everything and Fresh party can be undone.
- Screen readers announce decode results and messages, not every change to the password.
- The version at the bottom of the page links to this changelog.

## 1.0.3 (2026-10-15)
- Big text is the main button, since passwords are typed into the game, not pasted. The bar that appears while scrolling opens Big text too.
- Better search results: a fuller title and description, and an "About this generator" section.

## 1.0.2 (2026-10-15)
- README screenshots show the current page instead of cached copies.

## 1.0.1 (2026-10-15)
- The password fills the width of its box, so it's as large as possible on any screen.

## 1.0.0 (2026-10-15)
First numbered release.
- Passwords for SNES, Genesis / Mega Drive and Amiga (original and AGA), including the European releases.
- Decode a password, with fixes suggested for mixed-up characters.
- Big text view for reading the password while you type it in.
- Shopping list that works out each player's money.
- −/+ buttons for lives and level, and a Max button for each player's money.
