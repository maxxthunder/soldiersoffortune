# Names used in the listings. One per line: platform  kind  address  name  [bank]
#   kind code: a routine or data label; it replaces L_xxxxxx in the listing and reassembles to that address
#   kind ram:  a variable; it is shown at the end of the comment on every line that uses it
# SNES RAM below $10000 is the low page ($7E0000 mirror). A bank (e.g. CD) limits a direct-page name
# to code in that bank, because bank C0 moves the direct page onto object data.
# Genesis RAM is written as the full address; the listings show it as an offset from A5 ($FF0000).
# Names are lowercase. See docs/ram_map.md for what the variables hold.
